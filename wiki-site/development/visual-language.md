# Visual language

The target is the royal chancery at the end of a dynasty: vellum, ink, seals, ribbons, heraldry and
political-map composition. Generic dashboard cards, glassmorphism, neon, themed component kits and
vector icon sets are rejected.

WP-000 supplies only a clearly provisional smoke proclamation. WP-012 proves reusable visual fixtures
at 1280×720 and 1440×900 before UI fan-out.
