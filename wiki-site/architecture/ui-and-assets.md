# UI and assets

React reads projections through a thin Zustand adapter and dispatches typed commands. CSS Modules and
project tokens supply the visible system; Radix Primitives may provide difficult unstyled behavior.

Shipped game imagery is raster PNG/WebP. SVG assets, inline SVG icons, icon fonts and vector icon
packages are forbidden. The map will be a raster plate with semantic DOM hotspots. WP-012 owns the
visual language; WP-034 integrates the approved production asset pack.
